# Security scan

## Executive summary

State actual assessment/processing status and canonical/display finding counts.
Zero findings never proves security.

## Scope and environment

Target, revision or unknown, depth, explicit exclusions and uninspected areas.

## Scan methodology

Actual static paths, applicable categories and analysis limitations.

## Tools executed

Actual reviewed command/version, exit, configuration/scope and sanitized evidence.
Separate imported evidence, skipped/missing tools and producer failures.

## Findings by severity

Canonical counts and view threshold; filtering never deletes canonical records.

## Detailed findings

ID, category, severity/rationale, confidence, lifecycle status, location, evidence,
controls considered, impact, recommendation and verification requirements.

## Evidence and reproduction status

Source/evidence references, reported versus checked locations and actual test status.

## Recommended remediation

Prioritize supported practical impact; do not implement fixes without authorization.

## Suggested regression tests

Discriminating invariant negatives/controls; proposed tests remain unrun.

## Assessment limitations

Scope gaps, missing tools/evidence, privacy review and unresolved hypotheses.
