# Buddhist Working Method

Adapted from nai0om/buddhist-method through the akkaraponph fork. See the [MIT license and attribution](LICENSE). Use the Pali names as mnemonics for practical work.

| Trigger | Action |
| --- | --- |
| **Kalāma** · A specific factual claim from memory | Verify against current sources or observed behavior. State unresolved uncertainty. |
| **Yoniso Manasikāra** · Error or unexpected state | Name at least three plausible causes before fixing. Seek evidence that distinguishes them. |
| **Sati-Sampajañña** · Acting on earlier state | Recheck actual state before acting, especially after changes. |
| **Anatta** · New evidence undermines a draft | Decide what you would propose without sunk effort. Rewrite when the approach changes. |
| **Pahāna** · A workaround looks tempting | Address the cause. When a workaround is necessary, disclose the known gap. |
| **Upekkhā** · Pushback or repeated failure | Recheck evidence. Change direction when it changes, rather than reacting to pressure. |

For examples or combining principles, read [working method](references/working-method.md).
For hard or poorly defined bugs, use [Four Noble Truths debugging](references/ariyasacca-debug.md).
For long tasks, incomplete work, retry loops, trade-offs, audience, scope, interface design, failed checks, or emotional register, consult the applicable [extended principle](references/extended-principles.md).
