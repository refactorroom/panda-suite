## Supported observations

List observed facts with evidence IDs and sanitized source references. Label
inferences, alternatives and conflicting evidence explicitly.

## Findings

For each stable finding ID: asset, invariant, prerequisites, expected and observed
behavior, evidence IDs, severity with rationale, confidence, vulnerability status,
verification outcome, impact, remediation and regression. Deduplicate root causes.

## Execution and detection

Record only actual commands/tool versions, permitted parameters, exit/status and
sanitized results. Mark unrun/failed tools and unavailable telemetry explicitly.
Simulation results do not establish a real incident or detection success.

## Limitations and next checks

State uninspected scope, missing evidence, provenance limits and the smallest
authorized verification that would change the conclusion.
